# lab7 task2 Vehicle OOP Example

## Overview
This small Python project demonstrates core OOP concepts:
- **Encapsulation** via instance attributes
- **Inheritance** with `Vehicle` base class and `Car` and `Truck` child classes
- **Polymorphism** by calling overridden `start` methods on different objects
- **Method overriding** and custom behavior in child classes
- Code organized into modules following a simple project structure

## Files
- `models.py` — contains `Vehicle`, `Car`, and `Truck` classes
- `main.py` — demonstration script that imports models and runs examples
- `README.md` — this file
